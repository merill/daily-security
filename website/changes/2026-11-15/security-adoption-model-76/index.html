Security Adoption Model

15 November 2026Doc update+2 / −1 lines

In brief

The guidance now links to AI security transformation resources and includes the Zero Trust Workshop alongside assessment and technology implementation guidance.

What security teams need to know

Administrators get additional planning resources when navigating Zero Trust adoption; no action is required.

  • Start with a priority risk or problem when an urgent gap or high-value opportunity needs attention.
