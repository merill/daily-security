This guidance is part of the Microsoft Security Adoption Framework (SAF) and provides architecture-level implementation guidance within the Access and Identities discipline.

For conceptual context, start with Overview - privileged access. For implementation planning, use Establish a privileged access strategy, then continue to technical solutions for product-level implementation guidance.

Why a privileged access architecture?

Securing and governing privileged access is critically important because privileged access controls the identity system, management interfaces, and enforcement mechanisms that protect everything else.
