How Zero Trust workshop pillars map to SAF

The Zero Trust Workshop uses pillars as its organizing concept for planning and implementation. Most workshop pillars correspond to technologies in SAF, including identity, endpoints, applications, data, infrastructure, network, and AI.

Two workshop pillars map differently in SAF:

  • SecOps maps to the SAF SecOps security discipline.
  • DevSecOps/Development Security maps to the SAF Development Security security discipline.

This approach allows the Zero Trust Workshop to retain its familiar pillar-based structure while SAF distinguishes between technologies that must be protected and the security disciplines that perform security work across them.
