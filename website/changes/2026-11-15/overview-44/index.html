In brief

The overview now links to the Security Adoption Framework (SAF) for business-outcome guidance and Zero Trust Technologies deployment guidance for technology-area implementation steps. Several related metadata links were also updated or removed.

What security teams need to know

Administrators should use the updated guidance links when planning Zero Trust adoption and deployments. No configuration change or other required action is stated.
