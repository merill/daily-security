In brief

Microsoft added documentation distinguishing CIS Controls v8.1 for prioritizing security practices from CIS Benchmarks for technology-specific configuration, and mapping both to SAF roles, disciplines, technologies, and implementation guidance.

What security teams need to know

Security administrators can use the mappings to assign responsibilities, establish configuration baselines, validate compatibility, manage exceptions, and monitor improvements.

Map CIS Controls and CIS Benchmarks to SAF | Microsoft Learn

The Center for Internet Security (CIS) publishes two related but different forms of guidance:

  • CIS Controls v8.1 provide a prioritized set of cybersecurity practices and 153 Safeguards. They help organizations decide what security work to perform.
  • CIS Benchmarks provide prescriptive, consensus-based configuration recommendations for specific technologies and product families. They help technology owners decide how to configure an in-scope technology securely.

The Microsoft Security Adoption Framework (SAF) helps organizations assign the work to appropriate roles and disciplines, apply it across technologies, and connect it to architecture and implementation guidance.

Important

CIS remains the authoritative source for CIS Controls, Safeguards, Implementation Groups, and Benchmarks. This mapping doesn't replace CIS guidance, certify a configuration, or demonstrate that a CIS outcome has been achieved.

Use CIS Controls and Benchmarks for different decisions

GuidancePrimary questionUnit of workSAF use
CIS Controls v8.1Which cybersecurity practices and Safeguards should the organization implement and prioritize?Organization-level Controls and SafeguardsConnect outcomes to business context, security disciplines, accountable and responsible roles, technologies, and measurable improvement work.
CIS BenchmarksHow should a particular technology or service be securely configured?Technology-specific configuration recommendationsEstablish an approved security baseline, assign implementation to technology owners, validate compatibility, manage exceptions, and monitor configuration drift.

Map CIS Benchmark work to SAF roles

Use the applicable CIS Benchmark as the configuration source. SAF helps assign configuration work across the roles responsible for the technology and its security. Security and technology architects establish the baseline, Product Owners and other accountable leaders provide business context and approve risk decisions, and engineering and operations roles implement and maintain the configuration. Security Posture Management measures conformance and drift, SecOps/SOC roles investigate related security events, and compliance and audit roles validate applicable obligations and evidence. \ No newline at end of file
