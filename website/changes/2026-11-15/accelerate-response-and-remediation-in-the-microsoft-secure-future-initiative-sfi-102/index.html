Accelerate response and remediation in the Microsoft Secure Future Initiative (SFI) | Microsoft Learn

The Secure Future Initiative (SFI) initiative is a multiyear, cross-Microsoft initiative to increasingly secure the way in which Microsoft designs, builds, tests, and operates its products and services. SFI is build upon:

  • A set of security principles that drive the way in which we innovateThis pillar focuses on security design, implement those innovations into Microsoft products as secure defaults and standards, and provide internal and external security guidance. Learn more.
  • A set of prioritized security pillars and objectives. Learn more.

This article summarizes the "Accelerate response and remediation" SFI pillar.

Before you start

  • Learn about the SFI pillars.
  • Review and track the latest progress on pillar objectives in the SFI What's New article.
  • Pillar objectives map to Zero Trust principles, and to NIST CSF functions and categories.
  • Get a list of NIST categories and acronyms to help as you review the table in this article.

Pillar and objectives

The aim of this pillar is to quickly contain threats, restore trust, and improve resilience. It aims to minimize thereducing incident impact and duration of security eventsthrough faster mitigation, stronger coordination, and attacker dwellcontinuous learning.

Security outcome Microsoft prioritized

Microsoft prioritized reducing time in internal networks.
