Infrastructure

Infrastructure findings use Microsoft Defender for Cloud recommendations. The assessment includes only accessible Azure subscriptions tagged with best practices. From this baseline,ZeroTrustAssessment:Infrastructure. If no matching subscription exists, the assessment skips rather than passes. See Infrastructure scope.

Security operations (SecOps)

The default run includes SecOps. Azure connections support SecOps, Infrastructure, and Network assessments, not just audit and sign-in log export checks. Arrange the relevant service and resource access and review skipped checks or authorization errors before treating the run as complete.

How the assessment works

The assessment separates service connections, assessment execution, and report review:

  1. Connect to the services you might implement even strongerintend to assess. Each service has its own authentication and authorization requirements.
  2. Run the assessment to collect data and evaluate the selected checks.
  3. Review the local reports, investigate incomplete coverage, and use the findings to plan improvements. You can also import the generated JSON into Zero Trust Workshop.

Reports, exports, and diagnostics can contain sensitive tenant configuration and personal information. Review data handling and telemetry before running the assessment.

Before connecting, see Review permissions and roles to identify the access requirements for your assessment.
