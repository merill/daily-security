26 November 2026Doc update+3 / −2 lines

In brief

The ACSOP-1.3.10 mapping now lists Microsoft Perception instead of Project Perception (preview). Documentation metadata was also updated.

What security teams need to know

Administrators referencing this framework mapping will see the current product name; no action is required.
