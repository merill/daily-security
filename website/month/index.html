Month in brief

New SAF mappings connect Zero Trust frameworks to disciplines, roles, and capabilities

November’s substantive change is a new Security standards and frameworks page mapping framework objectives to SAF disciplines, roles, Microsoft security capabilities, and implementation guidance. It covers Zero Trust, the CISA Zero Trust Maturity Model, and the DoD Zero Trust Strategy. The core SAF guidance also expanded its explanation of business priorities, risk, Zero Trust principles, technologies, solutions, shared responsibilities, implementation, measurement, and four connected framework components. Most other updates were lower-impact date, metadata, capitalization, and internal-reference maintenance across security adoption, Zero Trust, AI security, and SecOps workshop content.

  • Security adoption · Standards and frameworks
    Framework objectives are mapped into the SAF operating model

    The new Security standards and frameworks guidance maps standards and framework objectives to SAF disciplines, organizational roles, Microsoft security capabilities, and implementation guidance. Its examples include Zero Trust, the CISA Zero Trust Maturity Model, and the DoD Zero Trust Strategy.

  • Security adoption · Standards and frameworks
    SAF now connects strategy, risk, responsibilities, and measurement

    The Microsoft Security Adoption Framework page now describes links among business priorities, risk, Zero Trust principles, security disciplines, technologies, and technical solutions. It also adds guidance on shared responsibilities, implementation, measurement, and four connected framework components.

  • Security adoption · General
    SAF navigation now uses objective- and role-based entry points

    Using SAF effectively replaces the previous top-down, build-up, and scenario-driven patterns with tables that direct readers by objective or organizational role to strategy, architecture, disciplines, scenarios, technologies, workshops, and related guidance.

For security architects and administrators

Security architects can use the new mappings to plan improvements and assess alignment with framework objectives, while the expanded SAF model supports responsibility assignment, implementation planning, and progress measurement across hybrid, multicloud, and multiplatform environments. The revised navigation can help route stakeholders to relevant guidance. No configuration, migration, or other mandatory administrator action is indicated.
