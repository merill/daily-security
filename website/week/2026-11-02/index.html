Week in brief

New SAF guidance maps Zero Trust frameworks to disciplines, roles, and Microsoft capabilities

The week added a new Security standards and frameworks page that maps framework objectives to SAF disciplines, roles, Microsoft security capabilities, and implementation guidance, including Zero Trust, the CISA Zero Trust Maturity Model, and the DoD Zero Trust Strategy. The core SAF guidance also now connects business priorities, risk, Zero Trust principles, technologies, solutions, shared responsibilities, implementation, and measurement through four connected framework components. Most other updates were lower-impact page-date, metadata, capitalization, and internal-reference changes across Zero Trust, AI security, and SecOps workshop and scenario content.

  • Security adoption · Standards and frameworks
    New standards-to-SAF mappings

    The new Security standards and frameworks guidance maps security standards and framework objectives to SAF disciplines, roles, Microsoft security capabilities, and implementation guidance. It includes mappings for Zero Trust, the CISA Zero Trust Maturity Model, and the DoD Zero Trust Strategy.

  • Security adoption · Standards and frameworks
    SAF now presents a connected operating model

    The Microsoft Security Adoption Framework page now explains the relationships among business priorities, risk, Zero Trust principles, security disciplines, technologies, and technical solutions. It adds guidance on shared responsibilities, implementation, measurement, and four connected framework components.

  • Security adoption · General
    SAF navigation shifts to goals and organizational roles

    Using SAF effectively now directs readers through tables based on their objectives or organizational role. These replace the previous top-down, build-up, and scenario-driven patterns with links to strategy, architecture, disciplines, scenarios, technologies, workshops, and related guidance.

For security architects and administrators

Security architects can use the new mappings and expanded SAF model to plan improvements, coordinate responsibilities, assess alignment with framework objectives, and track progress across hybrid, multicloud, and multiplatform environments. The updates to SAF navigation can help route stakeholders to relevant guidance; no configuration or migration action is indicated.
